# Семейный планировщик

Telegram-бот — общая «внешняя память» семьи: задачи, заметки, покупки, события,
напоминания и утренний дайджест в одном групповом чате.

- `docs/TASKS.md` — чеклист реализации, текущий прогресс и летопись этапов
- `CLAUDE.md` — как устроен код, обоснования решений и что нельзя ломать

## Подготовка бота

1. Создать бота у [@BotFather](https://t.me/BotFather), забрать токен.
2. `/setprivacy → Disable` — иначе бот не увидит обычные сообщения в группе.
3. **Удалить бота из группы и добавить заново** — без этого смена privacy
   не подхватится.
4. `cp .env.example .env` и вписать `BOT_TOKEN`.

Команд для инициализации нет: семья создаётся сама по первому сообщению в
группе, участники — по мере того, как они пишут.

## Запуск дома (основной путь)

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
run.cmd
```

`run.cmd` накатывает миграции и поднимает бота. Docker для этого не нужен.

**Автозапуск.** Планировщик задач Windows → создать задачу. Действие — не
`run.cmd` напрямую, а `cmd.exe` с редиректом: Планировщик стдаут никуда не
пишет, и без редиректа лога не остаётся вовсе.

```
Программа:      cmd.exe
Аргументы:      /c ""C:\Projeck\Family_planner\run.cmd" >> "C:\Projeck\Family_planner\data\bot.log" 2>&1"
Рабочая папка:  C:\Projeck\Family_planner
```

**Рабочая папка обязательна:** `.env` и `data/` ищутся от текущего каталога.
Ротации у `bot.log` нет — чистить руками раз в полгода.

На вкладке «Параметры» включить «Перезапускать при сбое», снять лимит времени
выполнения. На вкладке «Условия» снять «Запускать только при питании от сети» и
«Останавливать при переходе на батарею».

Триггер выбирается по тому, как поднимается прокси:

- прокси — обычное приложение из автозапуска → триггер **«При входе в систему»**
  с задержкой в минуту плюс автоматический вход в Windows (`netplwiz`);
- прокси — служба Windows → триггер **«При запуске компьютера»** и
  «Выполнять вне зависимости от регистрации пользователя».

Второй вариант надёжнее, но задача в нём работает в сессии 0, без рабочего
стола пользователя: приложения из пользовательского автозапуска там не
существует, и бот будет молча крутиться в рестартах, не найдя прокси.

Отдельно: отключить сон и гибернацию, иначе ночью бот просто не работает.

```bat
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
```

На ноутбуке этого мало — остаются сон от батареи и закрытие крышки:

```bat
powercfg /change standby-timeout-dc 0
powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0
powercfg /setdcvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0
powercfg /setactive SCHEME_CURRENT
```

## Переезд на другой ПК

Переносить надо три вещи: код, `.env` и базу. Код едет через git, остальное — в
`.gitignore` и копируется руками. Плюс четвёртое, чего в репозитории нет вовсе,
— задача Планировщика и прокси.

**На старой машине.** Закоммитить и запушить всё, иначе `git clone` на новой
даст код на этап назад. Слепок версий `pip freeze` — страховка: в
`requirements.txt` только диапазоны, лок-файла нет.

**На новой машине, пока старый бот ещё работает.** Python той же минорной
версии, прокси (проверить `curl.exe -x <прокси> https://api.telegram.org/`),
`git clone`, `python -m venv .venv`, установка зависимостей. Положить `.env` и
поправить в нём `TELEGRAM_PROXY`. **`.env` кладётся до миграций:**
`alembic/env.py` импортирует `bot.config`, и без `BOT_TOKEN` падает
`ValidationError`, не дойдя до базы. Прогнать `pytest`. Бота **не запускать**:
два long polling на одном токене дерутся за `getUpdates`.

**Перенос базы — здесь начинается простой.** Остановить бота на старой машине,
убедиться, что процессов `-m bot` не осталось, и скопировать **три** файла:
`data\family.db`, `data\family.db-wal`, `data\family.db-shm`. Именно три:
включён WAL, и в `-wal` лежат самые свежие записи — копия одного `family.db`
их потеряет. По желанию — `data\backups\` и `data\parse.log`, для работы они
не нужны.

Запасной путь, если копировать между машинами неудобно: **до** остановки нажать
`/backup` в чате — придёт самодостаточный снимок, `-wal` к нему не нужен. Цена:
база семьи навсегда осядет в облаке Telegram, а ежедневный бэкап держат на
диске именно чтобы этого не случилось.

**Первый запуск.** `alembic upgrade head` (на перенесённой базе no-op, но
проверяет, что `.env` читается), затем `run.cmd` глазами в консоль — должны
появиться «Запуск @…», «Тикер запущен» и «Run polling». Тишина после «Запуск»
без единой ошибки означает, что прокси не пропускает. В группе проверить
`/today` и `/family`: они покажут перенесённые данные, а не пустоту. Панель
«📌 Сегодня» бот продолжит **редактировать**, а не выпустит заново —
`panel_message_id` приехал вместе с базой.

**Погасить старую машину как источник.** Задачу Планировщика там удалить, а не
отключить: включённая по случайности, она даст второй экземпляр на том же
токене. `data\` не стирать пару недель — это единственная страховка.

**Что теряется, и это штатно:** незавершённые `/new`, неподтверждённые карточки
разбора, ожидания правки реплаем и приглашения «🎤 Голосом» — всё это живёт в
памяти процесса; плюс сообщения, пришедшие в чат за время простоя
(`drop_pending_updates=True` на старте). Напоминания не теряются — их догоняет
тикер из базы, но форма зависит от длины простоя: до `LATE_SILENT_MIN` минут
незаметно, до `LATE_SUMMARY_HOURS` часов с пометкой об опоздании, дольше —
одной сводкой.

## Переезд на VPS

Для сервера в репозитории лежат `Dockerfile` и `docker-compose.yml` — там
контейнер оправдан: одинаковое окружение и автоперезапуск. Системных
зависимостей у образа нет: `ffmpeg`, который закладывался под этап 5, не
понадобился — расшифровка принимает `ogg/opus` Telegram как есть.

```bash
# скопировать на сервер data/ и .env
chown -R 1000:1000 ./data   # процесс в контейнере не root и иначе не создаст БД
docker compose up -d
docker compose logs -f
```

## Стоимость LLM

Разбор свободного текста идёт через OpenRouter на модели
`minimax/minimax-m3:free`. Она бесплатна, поэтому фактическая цена —
**0 ₽/мес**. Цифра из наблюдения, а не из прайса: платить не за что.

Настоящая цена бесплатного тира — не деньги, а лимит запросов:

| Что | Сколько |
|---|---|
| Запросов в минуту | 20 |
| Запросов в сутки, без пополнения | 50 |
| Запросов в сутки, после разовой покупки кредитов на $10 | 1000 |

Лимит считается **глобально на аккаунт**, новые ключи его не обходят
(`https://openrouter.ai/docs/api-reference/limits`). Бот отзывается только на
явное обращение — команду, ответ на своё сообщение, упоминание или фразу с `+`,
— поэтому в сутки уходят единицы запросов и до лимита далеко.

**Замер 28.08.2026: 10 вызовов за сутки** (7 текстовых разборов и 3 голосовых)
— это 20 % суточного лимита. Причём день был не обычный, а день живых прогонов:
семья в этот день не столько пользовалась ботом, сколько проверяла его. Обычный
день будет меньше, но на одном замере это утверждать нельзя — цифра тут одна и
взята с потолка ровно настолько, насколько один день репрезентативен. Режим «слушать
всё» отменён именно из-за этой таблицы: вызов на каждое сообщение чата выбрал бы
суточный лимит, после чего перестал бы работать и префикс `+`.

**Пересчёт по логу** — понадобится при переходе на платную модель. Бот пишет
`data/parse.log` (JSON-строками, по строке `event=parse` на каждый разбор):

```bash
python -c "import json,collections;from pathlib import Path;c=collections.Counter((json.loads(l)['at'][:10], json.loads(l).get('via')) for l in Path('data/parse.log').read_text(encoding='utf-8').splitlines() if json.loads(l).get('event')=='parse');[print(d, v, n) for (d, v), n in sorted(c.items())]"
```

Печатает «дата · путь разбора (`llm` / `dateparser`) · сколько раз». Умножить
число `llm`-строк в сутки на цену модели за вызов — это и есть месячная смета.

## Стоимость расшифровки голоса

Второй внешний сервис и **вторая, независимая квота**: голосовые уходят в Groq
(`whisper-large-v3-turbo`), а не в OpenRouter. Это сделано намеренно — иначе
голос выедал бы те же 50 запросов в сутки, на которых держится текстовый `+`.

| Что | Бесплатный тир Groq |
|---|---|
| Запросов в минуту | 20 |
| Запросов в сутки | 2000 |
| Секунд аудио в сутки | 28 800 (8 часов) |
| Карта при регистрации | не нужна |

Сверх тира — $0.04 за час аудио. Для семейного чата это тоже **0 ₽/мес**.

Ключ берётся на `console.groq.com` и кладётся в `.env` как `STT_KEY`. Пока он
пуст, кнопка «🎤 Голосом» честно отвечает, что расшифровка выключена, а
остальной бот работает как раньше. Голосовые считаются отдельной строкой
`event=voice` в том же `data/parse.log`.
