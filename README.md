# Семейный планировщик

Telegram-бот — общая «внешняя память» семьи: задачи, заметки, покупки, события,
напоминания и утренний дайджест в одном групповом чате.

- `PLAN.md` — архитектура и обоснования решений
- `TASKS.md` — чеклист реализации, текущий прогресс

## Подготовка бота

1. Создать бота у [@BotFather](https://t.me/BotFather), забрать токен.
2. `/setprivacy → Disable` — иначе бот не увидит обычные сообщения в группе.
3. **Удалить бота из группы и добавить заново** — без этого смена privacy
   не подхватится.
4. `cp .env.example .env` и вписать `BOT_TOKEN`.

Команд для инициализации нет: семья создаётся сама по первому сообщению в
группе, участники — по мере того, как они пишут.

## Запуск дома (основной путь)

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
run.cmd
```

`run.cmd` накатывает миграции и поднимает бота. Docker для этого не нужен.

**Автозапуск.** Планировщик задач Windows → создать задачу:
триггер «При запуске компьютера», действие — запуск `run.cmd`,
на вкладке «Параметры» включить «Перезапускать при сбое» (каждую минуту).
Чтобы бот работал без входа в систему, в свойствах задачи выбрать
«Выполнять вне зависимости от регистрации пользователя».

Отдельно: отключить сон и гибернацию, иначе ночью бот просто не работает.

## Переезд на VPS

Для сервера в репозитории лежат `Dockerfile` и `docker-compose.yml` — там
контейнер оправдан: одинаковое окружение и автоперезапуск. Системных
зависимостей у образа нет: `ffmpeg`, который закладывался под этап 5, не
понадобился — расшифровка принимает `ogg/opus` Telegram как есть.

```bash
# скопировать на сервер data/ и .env
chown -R 1000:1000 ./data   # процесс в контейнере не root и иначе не создаст БД
docker compose up -d
docker compose logs -f
```

## Стоимость LLM

Разбор свободного текста идёт через OpenRouter на модели
`minimax/minimax-m3:free`. Она бесплатна, поэтому фактическая цена —
**0 ₽/мес**. Цифра из наблюдения, а не из прайса: платить не за что.

Настоящая цена бесплатного тира — не деньги, а лимит запросов:

| Что | Сколько |
|---|---|
| Запросов в минуту | 20 |
| Запросов в сутки, без пополнения | 50 |
| Запросов в сутки, после разовой покупки кредитов на $10 | 1000 |

Лимит считается **глобально на аккаунт**, новые ключи его не обходят
(`https://openrouter.ai/docs/api-reference/limits`). Бот отзывается только на
явное обращение — команду, ответ на своё сообщение, упоминание или фразу с `+`,
— поэтому в сутки уходят единицы запросов и до лимита далеко.

**Замер 28.08.2026: 10 вызовов за сутки** (7 текстовых разборов и 3 голосовых)
— это 20 % суточного лимита. Причём день был не обычный, а день живых прогонов:
семья в этот день не столько пользовалась ботом, сколько проверяла его. Обычный
день будет меньше, но на одном замере это утверждать нельзя — цифра тут одна и
взята с потолка ровно настолько, насколько один день репрезентативен. Режим «слушать
всё» отменён именно из-за этой таблицы: вызов на каждое сообщение чата выбрал бы
суточный лимит, после чего перестал бы работать и префикс `+`.

**Пересчёт по логу** — понадобится при переходе на платную модель. Бот пишет
`data/parse.log` (JSON-строками, по строке `event=parse` на каждый разбор):

```bash
python -c "import json,collections;from pathlib import Path;c=collections.Counter((json.loads(l)['at'][:10], json.loads(l).get('via')) for l in Path('data/parse.log').read_text(encoding='utf-8').splitlines() if json.loads(l).get('event')=='parse');[print(d, v, n) for (d, v), n in sorted(c.items())]"
```

Печатает «дата · путь разбора (`llm` / `dateparser`) · сколько раз». Умножить
число `llm`-строк в сутки на цену модели за вызов — это и есть месячная смета.

## Стоимость расшифровки голоса

Второй внешний сервис и **вторая, независимая квота**: голосовые уходят в Groq
(`whisper-large-v3-turbo`), а не в OpenRouter. Это сделано намеренно — иначе
голос выедал бы те же 50 запросов в сутки, на которых держится текстовый `+`.

| Что | Бесплатный тир Groq |
|---|---|
| Запросов в минуту | 20 |
| Запросов в сутки | 2000 |
| Секунд аудио в сутки | 28 800 (8 часов) |
| Карта при регистрации | не нужна |

Сверх тира — $0.04 за час аудио. Для семейного чата это тоже **0 ₽/мес**.

Ключ берётся на `console.groq.com` и кладётся в `.env` как `STT_KEY`. Пока он
пуст, кнопка «🎤 Голосом» честно отвечает, что расшифровка выключена, а
остальной бот работает как раньше. Голосовые считаются отдельной строкой
`event=voice` в том же `data/parse.log`.
